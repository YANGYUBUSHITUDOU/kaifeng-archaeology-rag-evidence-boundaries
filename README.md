# 开封考古文献问答证据边界：统计复算与公开准备材料

本包保存批量、隔离各270条机器评价标签、外部10题90条标签、30题问题、150条Top5文献页码定位、三套实际隔离提示指令、配置及统计复算脚本。它允许复算现有标签，不等于完整端到端重现生成过程。

运行：下载本仓库的`research_data_and_code.zip`和`reproduce.py`到同一目录，运行`python3 reproduce.py`。也可解压ZIP后运行`python3 code/recompute.py`。Python 3.10以上，无需第三方库。输出保存在`recomputed/`。独立评分返回后可用`python3 code/score_agreement.py A.csv B.csv`，CSV列为blind_id,verdict，值correct/partial/wrong。缺项或编号不一致会停止，退化κ不强行设成1。

独立统计单位为30道题；三轮不能当90个独立问题。以同题三轮平均值配对bootstrap，10000次，批量种子20261006、隔离种子20261007，分位区间为排序后的第250和9750项（从1计）。批量两校验路径初答不一致，不能因其结果将增益归于规则。机器评价与生成同属OpenAI服务，不能当独立人工金标准。

公开内容未含论文PDF、原文长摘录、完整答案、个人评分和匿名方法映射。完整证据与生成日志在作者本地保留，第三方论文访问依原出版社或机构权限。仅凭本包无法验证文本支持关系或重新评价全部答案，这是明确的公开与可复现性边界。

仓库公开的是统计复算材料，尚无DOI；原始证据访问与新人工评分状态见上文。代码与新编衍生数据的开放许可证需作者确认，不能将第三方原文授权一并推定。第三方论文内容不适用本仓库的共享范围，复用前需自行取得相应权限。
